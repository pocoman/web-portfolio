일하는 방식

시스템 사이의 빈틈을 메우고, 오래된 코드를 다시 살립니다.

여러 시스템이 얽힌 환경에서 데이터가 어긋나지 않게 흐르도록 만드는 일을 주로 해왔습니다. 외부 ERP와 앱 백엔드를 잇는 연동 계층, 변경분을 실시간으로 실어 나르는 CDC 이벤트 파이프라인, 수년째 운영 중인 대형 레거시의 유지보수와 API·SPA로의 전환까지 — 운영에 부담을 주지 않으면서 바꾸는 방법을 고민합니다.

  • 시스템 연동

    인터페이스 미들웨어, CDC 이벤트, DB 큐 재전송으로 이기종 시스템 사이 데이터 정합성을 지킵니다.

  • 레거시 현대화

    운영 중인 모놀리식을 멈추지 않고 REST API · SPA 구조로 점진 전환합니다.

  • 운영·트러블슈팅

    침해 대응, DB 마이그레이션, 부하 테스트까지 문제를 재현하고 근본 원인을 찾습니다.

  • 풀스택 폭

    PHP·Java 백엔드부터 Vue·React 프론트, .NET 데스크톱까지 필요한 층을 직접 다룹니다.
