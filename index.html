일하는 방식

시스템 사이의 빈틈을 메우고, 오래된 코드를 다시 살립니다.

여러 시스템이 얽힌 환경에서 데이터가 어긋나지 않게 흐르도록 만드는 일을 주로 해왔습니다. 외부 ERP와 앱 백엔드를 잇는 연동 계층, 변경분을 실시간으로 실어 나르는 CDC 이벤트 파이프라인, 수년째 운영 중인 대형 레거시의 유지보수와 API·SPA로의 전환, 느려진 쿼리의 원인 추적과 보안 패치까지 — 운영에 부담을 주지 않으면서 바꾸는 방법을 고민합니다.

  • 시스템 연동

    인터페이스 미들웨어, CDC 이벤트, DB 큐 재전송으로 이기종 시스템 사이 데이터 정합성을 지킵니다.

  • 레거시 현대화

    운영 중인 모놀리식을 멈추지 않고 REST API · SPA 구조로 점진 전환합니다.

  • 운영·트러블슈팅

    쿼리 튜닝, 보안 패치·침해 대응, DB 마이그레이션, 장애 원인 분석까지 문제를 재현하고 근본 원인을 찾습니다.

  • 풀스택 폭

    PHP·Java 백엔드부터 Vue·React 프론트, .NET 데스크톱까지 필요한 층을 직접 다룹니다.

보안

침해사고 대응

웹셸 업로드 취약점 경로를 규명해 운영·검증 환경에서 PoC로 재현하고, 임시폴더 실행 차단 등 근본 대책을 세웠습니다. 악성파일 탐지 알림은 로그 시간대 보정과 요청 흐름 분석으로 침해 없음을 판정했습니다.

보안

제로데이 CVE 긴급 패치

Apache 취약점에 대응해 Windows·Linux 혼합 서버의 Apache·PHP·프레임워크를 QA→운영 순으로 패치. 조사·백업·검증을 스크립트로 표준화하고 취약 의존성을 정리했습니다.

보안

비밀정보 관리

하드코딩 자격증명 스캔 도구를 비교해 detect-secrets를 도입하고, CI 잡에 박힌 API 키를 Credentials 바인딩으로 일괄 전환했습니다.

장애

토큰 경쟁 조건 장애

에러 로그 약 44만 건 폭주를 분 단위·계정 단위로 분석해 DDoS를 배제하고, 트랜잭션 없는 delete→insert의 경쟁 조건을 근본 원인으로 규명했습니다.

장애

CDC 파이프라인 점검

정지된 CDC의 원인을 LSN·DDL 이력·스키마 드리프트로 추적해 진단했습니다.

인프라

Redis 런타임 교체

Docker를 쓸 수 없는 Windows Server에서 구형 Redis를 WSL1 기반 Redis 8로 교체. 재개 가능한 단계형 스크립트로 진행하고 앱 코드는 수정하지 않았습니다.

인프라

클라우드 백업 아키텍처

NAS 물리 백업을 클라우드 오브젝트 스토리지로 이관. 스토리지 티어·비용을 비교 검토하고, NAS 용량 차이 원인 진단 절차를 문서화했습니다.

연동

본인인증 SDK 연동

인증 예외를 조사하고 최신 라이브러리 교체 리스크를 분석해 안전한 방향을 제시했습니다.

컴플라이언스

인증 심사·법규 대응

ISMS 심사 질의·증빙에 대응하고 WAF Rate-based Rule로 보완했습니다. 개인정보보호법 기준에 맞춘 API 접속기록을 설계했습니다.

공유와 도구

혼자 아는 것에서 끝내지 않습니다.
